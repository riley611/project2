Project 2 - Automating Secure Coding with CI/CD Pipelines

Your objective for this project is to research and deploy a static analysis tool for Python and incorporate into a workflow when developing the code using the desktop environment configured in Unit 1. To test this workflow, you will design and code a moderately complex Python application using secure coding best practices including verification strategies for code review, automated static analysis and linting.

Deliverables

1.
A well-written, organized Word document fulfilling the following specific requirements:
a.
Research Results – For each tool and IDE plug-in selected describe its overall functionality, explain why it was selected over competing alternatives, identify any licensing or cost considerations.
b.
CI/CD workflow demo – Describe and document your initial tests with including a static code analysis tool and linter in a pipeline when you push code to the repository. Describe and include the major components of your requirements.txt, requirements-dev.txt and .yml files. Provide screenshots of your initial tests. Be sure to demonstrate successful and unsuccessful tests for both the linter and the static code analysis tool.
c.
Describe code review techniques you envision including. This should include manual and automated testing. All code review techniques do not need to be implemented but you should describe each one and discuss their strengths and weaknesses.
d.
Functionality testing – A description and screenshots should be provided walking through all major functionality of the application. A summary of the Unit testing results should be included as well.
e.
Labeled Screenshots that include a description.
f.
The document should include a title page, page numbers, APA formatted references and provide a logical flow using paragraph-style writing as opposed to bullets.

2.
Python code (e.g. marcoriley-project2.zip) – The code submitted should be the results of your AI-Assisted Application Development.
